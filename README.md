## 実行順序

```
① 被保険者推計 → ② 厚生年金給付費推計 ┐
                  ③ 国民年金          ├→ ④ 基礎年金 → ⑤ 収支計算
                                      ┘
（別建て）⑥ 分布推計
```

依存関係は「まず被保険者が何人いるか」→「厚生年金の給付はいくらか」→
「基礎年金の負担はいくらか」→「収支は合うか」の順です。

## 扱ううえでの注意

### 文字コード

ソースは **EUC-JP**（Solaris/UNIX由来）。そのまま開くと文字化けします。

```bash
iconv -f EUC-JP -t UTF-8 papers/001365945/プログラム/国民年金/main.c
```

`.gitattributes` で `* -text` を指定し、改行・テキスト正規化を無効化して
**バイト単位で原本を保全**しています。

### そのままでは実行できません

1. **絶対パス依存** — Makefile の出力先が `/suuri/rev2024/emp/exec/...` 固定
2. **データ欠落** — `bunpu/kisosuu/` がディレクトリごと存在しない。中間ファイルも未同梱
3. **入力テンプレート未記入** — `io_file/infile.csv` は空テンプレート

計算方法を検証可能にするためのソース公開であり、再実行は想定されていません。
詳細は仕様書 §12。

### 数値検証は未実施

仕様書の式は静的読解と法定パラメータとの照合によるものです。
上記のデータ欠落により、実際に流して公表値と突き合わせる検算はできていません。

## 要確認事項

`厚生年金/給付費推計/seid.cpp:26-30` の定額部分単価テーブル（生年度別）で、
1936年度生まれの値が `369` となっています。前後が `1413` → `1327` と
滑らかに逓減する中でここだけ跳んでおり、法定値 `1.369` の誤記と思われます。

影響は限定的と推定（新規裁定でのみ使用され、当該コホートの定額部分裁定は
推計開始年度より前に終了）。原本との照合が必要です。詳細は仕様書 §5.5。
