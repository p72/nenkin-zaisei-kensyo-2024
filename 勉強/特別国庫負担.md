# 特別国庫負担について厚労省のC/C++コードで解説する

2024年財政検証で厚生労働省が公表した計算プログラムを読みながら、
**特別国庫負担**（保険料の納付と結びつかない基礎年金の給付を、頭割りの外で国庫が持つ部分）が
コードの上でどう計算されているかを追う。

- コードは原本 `papers/001365945/プログラム/` のもの。行番号は EUC-JP を UTF-8 に
  変換したコピーで確かめた（原本とは行がずれない）
- 数字は、このリポジトリで計算プログラムを動かした出力から取った（過去30年投影）。
  現行制度と適用拡大は公表の財政見通しと照合済み
- 先に [国庫負担.md](国庫負担.md) と [基礎年金拠出金.md](基礎年金拠出金.md) を読むと分かりやすい

---

## 0. 何が「特別」なのか

基礎年金の国庫負担は、ふつうは「給付費の1/2」を**頭割り**で各制度に配る
（[国庫負担.md](国庫負担.md)）。ところが、保険料を払っていない期間や人に対応する給付は、
頭割りの前提（保険料を納めた頭数に応じて負担する）に乗らない。そこで、その部分だけを
**頭割りから外し、別建てで国庫が持つ**。これが特別国庫負担である。

コードでは、給付を次の2つに分けて持つ。

| 区分 | 定数 | 扱い |
|---|---|---|
| 拠出金の対象 | `KYOSHUTU` | 頭割りで各制度に配る。国庫はその1/2 |
| 特別国庫の対象 | `TOKUBETU` | 頭割りに入れない。全額を国庫が持つ |

## ステップ1：6つの種類と割合（④`dtst.c:63-77`、`snaps.h:72-78`）

[`基礎年金/dtst.c`](../papers/001365945/プログラム/基礎年金/dtst.c)。

```c
#define TOKUBETU_MENJO      1    // 免除
#define TOKUBETU_KASAAGE    2    // 嵩上げ（納付）
#define TOKUBETU_KASAMENJO  3    // 嵩上げ（免除）
#define TOKUBETU_SHITASASAE 4    // 老齢福祉年金の下支え
#define TOKUBETU_GONEN      5    // 5年年金
#define TOKUBETU_20MAE      6    // 20歳前障害

Tokubetu_Kokko_Wariai[年度][TOKUBETU_MENJO]      = 1.;          // 全額
Tokubetu_Kokko_Wariai[年度][TOKUBETU_KASAAGE]    = 1. / 4.;
Tokubetu_Kokko_Wariai[年度][TOKUBETU_KASAMENJO]  = 1.;
Tokubetu_Kokko_Wariai[年度][TOKUBETU_SHITASASAE] = 1.;
Tokubetu_Kokko_Wariai[年度][TOKUBETU_GONEN]      = 1. / 8.;
Tokubetu_Kokko_Wariai[年度][TOKUBETU_20MAE]      = 38. / 100.;  // 2008年度まで
if( nendo >= 2009 )
    Tokubetu_Kokko_Wariai[年度][TOKUBETU_20MAE]  = 2. / 10.;    // 2009年度から
```

割合は「その給付のうち何割を特別国庫に回すか」である。残りは拠出金の対象に入り、
そこでさらに1/2の国庫負担がかかる。

| 種類 | 何の給付か | 特別国庫に回す割合 |
|---|---|---|
| **免除** | 保険料免除期間に対応する老齢基礎年金など | 国庫の分の全部（下で説明） |
| 嵩上げ（納付・免除） | 旧法の老齢年金の嵩上げ分（原本の出力見出しは「嵩上げ（納付）」「嵩上げ（免除）」） | 1/4・全額 |
| 老福下支え | 老齢福祉年金の下支え | 全額 |
| 5年年金 | 経過的な特例の年金 | 1/8 |
| **20歳前障害** | 20歳前に障害を負った人の障害基礎年金（保険料を払う前） | 2/10 |

嵩上げ・老福下支え・5年年金は旧法（1986年4月の基礎年金の導入より前の制度）の経過的な給付で、
受給者が減り、この試算では2040年度にはゼロになる。**これから先の特別国庫負担は、ほぼ「免除」と「20歳前障害」の2つ**である。

## ステップ2：免除期間の年金を2つに割る（③`siml.c:1030-1050`）

免除期間の年金額は、数式モデル §5.1 のとおり、次の2つの和になっている。

```
免除期間1か月の年金 ＝ 満額/480 × ( β_d              ← 本人が払った保険料の分
                                  + γ·(1 − β_d) )   ← 国庫の分
    β_d：保険料を払う割合（全額免除 0、3/4免除 0.25、半額免除 0.5、1/4免除 0.75）
    γ  ：国庫負担割合（2009年度から 1/2）
```

③国民年金は、この2つを**別の欄に分けて**④に渡す。

[`国民年金/siml.c`](../papers/001365945/プログラム/国民年金/siml.c)。

```c
// 本人が払った分 → 納付の欄（拠出金の対象）
Rorei_Shinki[…].noufu         += Full_Pension * Kyufu_ritu * Hokenryou_Wariai[dankai] * 免除月数 / 可能年数 …;
// 国庫の分 → 免除の欄（特別国庫の対象）
Rorei_Shinki[…].menjo[dankai] += Full_Pension * Kyufu_ritu * Kokko_Wariai[kokko]
                                   * ( 1. - Hokenryou_Wariai[dankai] ) * 免除月数 / 可能年数 …;
```

たとえば全額免除の1か月は、満額の1/480 × 1/2 が年金になる（「全額免除でも年金の半分はもらえる」）。
その1/2は**全部が国庫の分**なので、全部が特別国庫負担になる。

## ステップ3：④で拠出金の対象と特別国庫に振り分ける（④`Atamawari.c:649-735`）

[`基礎年金/Atamawari.c`](../papers/001365945/プログラム/基礎年金/Atamawari.c) の
`cal_kyufu_nendomatu()`。国民年金の給付を `KYOSHUTU` と `TOKUBETU` に振り分ける。

```c
// 新法の老齢基礎年金：納付の欄 → 拠出金の対象
kyufu[KOKUNEN][…][NEW][ROREI][KYOSHUTU][KIHON] += rorei_new[KOKUNEN][…][NOUFU];
// 新法の老齢基礎年金：免除の欄（国庫の分）→ 全部 特別国庫
for( noufu_joutai = MENJO_ZENHAN ; noufu_joutai <= MENJO_KOUHAN ; noufu_joutai++ )
    kyufu[KOKUNEN][…][NEW][ROREI][TOKUBETU][KIHON] += rorei_new[KOKUNEN][…][noufu_joutai];

// 20歳前障害：8割 → 拠出金の対象、2割 → 特別国庫
kyufu[KOKUNEN][…][NEW][SHOGAI][KYOSHUTU][…] += shogai_new[…][HATACHIMAE][…] * ( 1. - 2/10 );
kyufu[KOKUNEN][…][NEW][SHOGAI][TOKUBETU][…] += shogai_new[…][HATACHIMAE][…] * 2/10;
```

被用者年金（厚年・共済）の側（737行目〜）には `TOKUBETU` への振り分けがない。
**特別国庫負担は、すべて国民年金の給付から出る。**

### 20歳前障害の国庫負担は全部で6割

20歳前障害の障害基礎年金は、2割が特別国庫、残り8割が拠出金の対象で、その半分（4割）にも
国庫負担がかかる。合わせると**国庫負担は6割**になる。

```
2/10（特別国庫） ＋ 8/10 × 1/2（ふつうの国庫負担） ＝ 6/10
```

2008年度までの割合（38/100、国庫負担 1/3＋2.5%）でも、38% ＋ 62% × 35.8% ≒ 60% と、
ほぼ同じ6割になるように決めてある。

## ステップ4：マクロ経済スライドのカットもかかる（④`Atamawari.c:186-275`）

特別国庫の対象の給付にも、拠出金の対象と同じカット率（`Cut_ritu`）が掛かる。

```c
for( taishou = KYOSHUTU ; taishou <= TOKUBETU ; taishou++ )     // 両方に
    Kyufu_Nendomatu[…][taishou][…] *= Cut_ritu[sotai_nendo][nenrei - UNDER_63];

// 種類別の内訳（出力用）にも同じカット
Tokubetukokko_Nendomatu[…][tokubetu_shurui][…] *= Cut_ritu[sotai_nendo][nenrei - UNDER_63];
```

そのため、**基礎年金の水準が上がれば特別国庫負担も上がり、下がれば下がる**。
ここは[国庫負担.md](国庫負担.md) のふつうの国庫負担と同じである。

---

## ステップ5：国民年金の財布では「通り抜け」（④`printout.c`、`tyousei.c`）

特別国庫負担は、国民年金の収支に**収入と支出の両方に同じ額**で立つ。

- 収入：「国庫（特別国庫）」（`printout.c:457`）
- 支出：「基礎年金拠出金（特別国庫）」（`printout.c:502`）

積立金の漸化式（`tyousei.c:42-54`）には、どちらも入っていない。差し引きゼロなので、
**国民年金の積立金にも、基礎年金の水準（終了年度）にも影響しない**。
国庫から入ったお金が、そのまま基礎年金勘定へ出ていく形である。

## 数字：過去30年投影

④の出力 `kekka…a.csv` の「特別国庫負担内訳」から（兆円・名目）。

| 年度 | 合計 | 免除 | 20歳前障害 | 旧法の3種 | （参考）ふつうの国庫負担 |
|---|---|---|---|---|---|
| 2024 | 0.45 | 0.23 | 0.21 | 0.001 | — |
| 2027 | 0.51 | 0.28 | 0.23 | 0.0003 | 13.44 |
| 2040 | 0.81 | 0.55 | 0.25 | 0 | — |
| 2060 | 1.07 | 0.80 | 0.27 | 0 | 14.94 |
| 2100 | 1.24 | 0.90 | 0.34 | 0 | 16.73 |

- 規模は、ふつうの国庫負担（基礎年金の給付費の1/2）の**約4%（2027年度）から約7%（2060年度以降）**である
- **免除の分が伸びる。** いま受け取っている人より、これから受け取る人のほうが免除期間を
  多く持っている（1990年代以降に免除者が増えた世代が受給年齢に入ってくる）ためと考えられる（推定）

### 適用拡大のときの動き

| 2060年度 | 合計 | 免除 | 20歳前障害 |
|---|---|---|---|
| 現行制度 | 1.07 | 0.80 | 0.27 |
| 適用拡大（約860万人） | 1.29 | 0.93 | 0.35 |

適用拡大で特別国庫負担も**増える**。免除期間や20歳前障害の人数が増えるのではなく、
基礎年金の水準が上がる（カットが浅くなる）ためである（ステップ4）。
ふつうの国庫負担と同じく、基礎年金の水準と一緒に動く。

## 読むときの注意

- **「特別」は財源の区分で、給付の区分ではない。** 受け取る人の年金額の計算は同じで、
  その費用を頭割りに乗せるか（拠出金）、国庫が直接持つか（特別国庫）の違いである
- **国民年金の積立金には効かない。** 収入と支出が同額の通り抜けなので、財政の均衡
  （終了年度）の計算には入ってこない
- **基礎年金の水準とは連動する。** カットがかかるので、水準を上げる制度変更では一緒に増える
- **免除期間の年金のうち、本人が払った分（β）は拠出金の対象**に残る。免除期間の年金が
  全部特別国庫になるわけではない
