# 有限均衡方式について厚労省のC/C++コードで解説する

2024年財政検証で厚生労働省が公表した計算プログラムを読みながら、
**有限均衡方式**（おおむね100年の財政均衡期間の終わりに、給付1年分の積立金が残るように
給付水準を決める仕組み）がコードの上でどう書かれているかを追う。

- コードは原本 `papers/001365945/プログラム/` のもの。行番号は EUC-JP を UTF-8 に
  変換したコピーで確かめた（原本とは行がずれない）
- 数字は、このリポジトリで計算プログラムを動かした出力から取った（現行制度）。
  公表の財政見通しと照合済み
- [マクロ経済スライド.md](マクロ経済スライド.md) のステップ5・7を、「何を均衡させているか」の側から
  読み直したのがこの文書。先にそちらを読むと分かりやすい
- 数式としての整理は [年金財政検証_数式モデル.md](../年金財政検証_数式モデル.md) の §7・§8

## 0. 制度としての有限均衡方式

厚生労働省の説明では、2004年改正で次のように決めた
（[財政検証の仕組み](https://www.mhlw.go.jp/nenkinkenshou/finance/finance03.html)、
[給付と負担の均衡を図るための財政期間](https://www.mhlw.go.jp/topics/nenkin/zaisei/zaisei/04/04-155.html)）。

- **おおむね100年間**で財政の均衡を図る（財政均衡期間）
- 期間の終わりに**給付費1年分程度の積立金**を持つ。それ以外の積立金は計画的に取り崩して、
  後の世代の給付に充てる
- 少なくとも5年ごとに「財政検証」で見通しを作り直す

保険料は上限（厚生年金18.3%、国民年金17,000円×改定率）で固定されているので、
均衡させるために動かせるのは**給付水準だけ**である。給付水準はマクロ経済スライドで下げていき、
**いつ調整をやめれば均衡するか**（調整終了年度）を解く。これが財政検証の「答え」になる。

## ステップ1：定数（④`cntl.c:81-94`）

[`基礎年金/cntl.c`](../papers/001365945/プログラム/基礎年金/cntl.c)。

```c
T_NENDO = 2120;    // 財政均衡期間の終了年度（2024年財政検証 → 約100年後）
T_DOAI  = 1;       // 期間の終わりに残す積立金（支出の何年分か）
KAISHI1 = 2023;    // 積立金を回し始める年度
C_NENDO = 2004;    // 調整の年度を数える起点（2004年改正）。候補は C_NENDO+1 から
```

⑤も同じ値を別の場所で持つ（`shus_calc.c:201` の `kend = … + 100` で2120年度、
`cntl.c` の `Ca = 1.0`）。

---

## ステップ2：積立金を1年ずつ回す

### 国民年金の財布（④`tyousei.c:42-54`）

[`基礎年金/tyousei.c`](../papers/001365945/プログラム/基礎年金/tyousei.c)。

```c
Tumitate[k] = Tumitate[k-1] * interest_rate[k]                     // 前年度末 × (1＋運用利回り)
  + ( 保険料 + 国庫負担 + … − 基礎年金拠出金 − 独自給付 … )        // 収支差
    * pow( interest_rate[k] , 1. / 2. );                             // 年度の途中で出入りする分の利息
```

収入と支出は年度の真ん中で平均的に出入りすると考え、収支差には**半年分の利息**
（`√(1＋利回り)`）を付ける。

### 厚生年金の財布（⑤`shus.c`・`shus_shushi()`）

⑤は `Cc[制度][項目][年度]` という表で収支を持つ。**`Cc[…][20]` が年度末積立金、
`Cc[…][11]` が支出合計**である（数式モデル §7.2）。

## ステップ3：均衡条件

### 国民年金（④`tyousei.c:114`）

```c
if( Tumitate[T_NENDO - 1] < Shishutu[T_NENDO] * T_DOAI )    // 2119年度末の積立金 ＜ 2120年度の支出
    … まだ足りない → 調整を1年延ばす
```

### 厚生年金（⑤`shus_calc.c:265, 282-283`）

```c
f1 = Cc[ii][20][kend-1] - Cc[ii][11][kend] * Ca;    // 2119年度末の積立金 − 2120年度の支出
if(f1 >= 0.0 && k >= k_jisseki){ kn = k; … }        // 初めて足りた年度 → 終了年度
```

どちらも同じ式である。

> **2119年度末の積立金 ≥ 2120年度の支出 × 1**

添字が `T_NENDO − 1`（`kend − 1`）なのがポイントで、「**2120年度の初めに**、その年度の
支出1年分がある」ことを求めている。2120年度の**末**には1を少し下回る。

**積立度合**はこの比のことで、財政見通しの表では毎年度「前年度末積立金 ÷ 当年度の支出合計」
として出てくる。

## ステップ4：答えを探す

調整を長く続けるほど給付が減り、積立金が残る。そこで、条件を**初めて**満たす終了年度を探す。

1. **1年刻み**で候補を試す（④`tyousei.c:66-129`、⑤`shus_calc.c:268-290`）
2. 最後の1年を**二分法128回**で合わせる（④`tyousei.c:133-230`、⑤`rrh_max`・`rrh_min` から）

こうして、2120年度初の積立度合が**ちょうど1**になるように給付水準が決まる。
詳しい手順は [マクロ経済スライド.md](マクロ経済スライド.md) のステップ5。

### 答えが「角」に張りつくとき

探す範囲には上と下の端がある。そこに張りついたときは、均衡の解ではない。

| 端 | 何が起きているか | コードの出力 |
|---|---|---|
| **上の端**（調整なし） | 2024年度で調整をやめても積立金が余る | 終了年度 2024、累積カット率 0.990024 |
| **下の端**（均衡しない） | 2120年度まで調整を続けても足りない | ④「調整できません」（`tyousei.c:118`）、⑤「最終年度まで調整しても均衡できませんでした」 |

上の端では、2120年度の積立度合が1を超えて**積立金が余ったまま**になる。
下の端では、途中で積立金が尽きる。[3号廃止の検証](../検証/3号廃止/README.md)では、
両方の端が実際に出てくる（按分据置型（国年充当）は上の端、第1号移行型は下の端）。

## ステップ5：2段階で解く — 基礎年金が先、報酬比例が後

国民年金と厚生年金は財布が別なので、**それぞれで均衡させる**。

```
STEP 1（④）  国民年金の財布が均衡するように、基礎年金の調整終了年度を決める
                ↓ 決まった基礎年金の水準（＝基礎年金拠出金）を前提にして
STEP 2（⑤）  厚生年金の財布が均衡するように、報酬比例の調整終了年度を決める
```

| ケース | 基礎年金 | 報酬比例 | 所得代替率 |
|---|---|---|---|
| 過去30年投影 | 2057年度まで・25.5% | 2026年度まで・24.9% | 50.4% |
| 高成長実現 | 2039年度まで・31.9% | 調整なし・25.0% | 56.9% |

**基礎年金の水準は国民年金の財布だけで決まり、報酬比例の水準は基礎年金の水準と
厚生年金の財布の両方で決まる。** 国民年金の支出の大部分は基礎年金拠出金なので、
国民年金は基礎年金を調整することでしか均衡できないからである。

その結果、基礎年金の調整は長く、報酬比例の調整は短くなる。厚生労働省もこの差の理由として
「国民年金と厚生年金のそれぞれの財政が均衡するまで行う必要がある」ことを挙げている
（[年金制度の仕組みと考え方 第7](https://www.mhlw.go.jp/stf/nenkin_shikumi_007.html)）。
2つの財布を1つにして一緒に均衡させるのが [調整期間の一致.md](調整期間の一致.md) である。

## 積立度合はどう動くか（過去30年投影・現行制度）

財政見通しの「積立度合」（前年度末積立金 ÷ 当年度の支出）。

| 年度 | 2024 | 2030 | 2040 | 2050 | 2060 | 2080 | 2100 | **2120** |
|---|---|---|---|---|---|---|---|---|
| 厚生年金 | 5.2 | 6.0 | 6.5 | 6.8 | 6.9 | 6.2 | 4.4 | **1.0** |
| 国民年金 | 3.8 | 4.0 | 3.7 | 3.4 | 3.3 | 2.9 | 2.2 | **1.0** |

しばらく積み上がったあと取り崩しに入り、**2120年度にちょうど1**に着地する。
「100年後に1年分だけ残して、あとは使い切る」という有限均衡の形が、数字にそのまま出ている。

## まとめの図

```
保険料は固定 ─┐
経済前提     ├→ 積立金を2120年度まで回す（収支差に半年分の利息）
給付水準 ────┘         │
    ↑                  ↓
    │     2119年度末の積立金 ≥ 2120年度の支出 × 1 ？
    │          いいえ → 調整を1年延ばす
    └──────── はい   → その年度が終了年度（最後の1年は二分法）

STEP 1 国民年金の財布 → 基礎年金の水準
STEP 2 厚生年金の財布 → 報酬比例の水準
```
