# 被用者保険の適用拡大について厚労省のC/C++コードで解説する

2024年財政検証で厚生労働省が公表した計算プログラムを読みながら、
**適用拡大**（パートなど短時間で働く人を厚生年金・健康保険に入れる範囲を広げること）が
コードの上でどう定義され、どこに効くのかを追う。

- コードは原本 `papers/001365945/プログラム/` のもの。行番号は EUC-JP を UTF-8 に
  変換したコピーで確かめた（原本とは行がずれない）
- 入力データは `papers/001365945/データ/suuri/rev2024/wakuc/data/part/`
  （実行領域では `work/suuri/rev2024/wakuc/data/part/`）
- 制度の説明は厚生労働省
  [「年金制度の仕組みと考え方 第9 被用者保険の適用拡大」](https://www.mhlw.go.jp/stf/nenkin_shikumi_009.html)
- 拠出金の仕組みは [基礎年金拠出金.md](基礎年金拠出金.md) を先に読むと分かりやすい

---

## 0. 入り口：`KAKUDAI` の番号

`検証/実行/run_pipeline.sh` の環境変数 `KAKUDAI` がスイッチである。
選択肢は原本①
[`被保険者推計/cntl.c`](../papers/001365945/プログラム/被保険者推計/cntl.c)（20〜70行目）の表示そのまま。

| `KAKUDAI` | 原本の表記 |
|---|---|
| 0 | 適用拡大なし（現行制度） |
| 1 | 90万人ベース（企業規模要件撤廃＋個人5人以上の非適用業種解消） |
| 2 | 200万人ベース（1に加えて賃金要件撤廃） |
| 3 | 270万人ベース（2に加えて個人5人未満） |
| **4** | **860万人ベース（週10時間以上の全ての雇用者）** |
| 5 | 最低賃金が2030年代半ばに1,500円になった場合 |

この番号は①②③⑤に渡る。**④基礎年金は受け取らない**（`run_pipeline.sh` 冒頭の
レバー対応表にもそう書いてある）。

## 1. ①被保険者推計：「誰が何人、どこから移るか」

### 入力データ：厚労省が用意した人数表

`partnin2020-2027-{KAKUDAI}.csv`（1段階目）と `partnin2020-2029-{KAKUDAI}.csv`（2段階目）に、
新しく厚生年金に入る人数が次の組み合わせごとに入っている。

- 年齢区分（11区分、5歳刻み）
- 男女
- 週の労働時間（20〜30時間／30時間以上／20時間未満）
- **元の区分（1号／3号／非加入）**

読み込みは
[`被保険者推計/readdata.c`](../papers/001365945/プログラム/被保険者推計/readdata.c)
（343行目で2024年10月分、373〜404行目で1段階目、405〜417行目で2段階目）。

集計すると次のとおり（基準年度 `PARTKYR = 2023` の人数、万人）。

| ファイル | 合計 | 元1号 | 元3号 | 元非加入 | 週20時間未満 |
|---|---|---|---|---|---|
| `partnin2020-2024.csv`（2024年10月の分） | 20 | 8 | 8 | 4 | 0 |
| `-2027-1` | 110 | 50 | 37 | 23 | 0 |
| `-2027-2` | 220 | 80 | 95 | 45 | 0 |
| `-2027-3` | 290 | 136 | 99 | 54 | 0 |
| **`-2027-4`** | **880** | **386** | **294** | **200** | **410** |

**2024年10月の20万人を引くと、90／200／270／860万人とぴったり合う。**
選択肢の「◯万人ベース」は、この差分のことである。

860万人の内訳は、元1号 378万・元3号 286万・元非加入 196万。
**週20時間未満（410万人）が入るのは4番だけ**である。

### 計算の中身（[`被保険者推計/simlpart.c`](../papers/001365945/プログラム/被保険者推計/simlpart.c)）

1. **将来に伸ばす**（62〜101行目）。基準年度の人数を、短時間雇用者の伸びに比例させる。

   ```c
   kbetu_partnin[年度][性][年齢区分][元の区分][時間][段階]
     = kbetu_partkiso[性][年齢区分][元の区分][時間][段階]
       * kbetu_tankoj[年度][性][年齢区分][時間] / kbetu_tankoj[PARTKYR][性][年齢区分][時間];
   ```

   同じ場所で、原本は次の2つを読み替える。
   - 20〜59歳（年齢区分2〜9）の「非加入」は1号として数える（88〜92行目）
   - 週30時間以上（`tkubun == 2`）の「元3号」は「元1号」として数える（93〜97行目）

2. **各歳の割合に直す**（108〜160行目）。5歳刻みの移る人数を、その年齢区分にいる
   今の1号・3号の人数で割って、割合 `p_wari` にする。

3. **1号・3号から引く**（20〜59歳は252〜310行目）。各歳の移る人数を
   「今の1号・3号の人数 × 割合」で出す。3号は、制度ごとの3号の構成比で厚年・共済に分けてから、
   実施年度以降の1号・3号から引く。

   ```c
   ichigou[1][…] -= partnin[…][1][tkubun][段階];   // 1号を減らす
   sangou[1][…]  -= partnin[…][3][tkubun][段階];   // 3号を減らす（厚年。共済は4〜6）
   ```

   段階の切り替わりは、1段階目が2027年度（`PARTYR1`）、2段階目が2029年度（`PARTYR2`）
   （`cntl.c` の各 `case`）。860万人ベースは2つのファイルの中身が同じなので、
   実質2027年度に一度に移る。60〜69歳にも同じ形のブロックがある（333行目〜）。

4. **2号に足す**。移った人の合計を `partnin[…][0][0][0]` に積み（575〜585行目）、
   [`被保険者推計/fout.c`](../papers/001365945/プログラム/被保険者推計/fout.c) が
   厚生年金の人数に足して外枠ファイル `waku{外枠番号}-*.csv` に書く（41〜70行目）。
   外枠には「適用拡大１段階目元１号」「元３号」「元その他」のような内訳の列もある（474〜484行目）。

### 実際にどれだけ動くか（過去30年投影、外枠 3003 → 3403）

①の出力から、20〜59歳・年度末で見ると、2027年度に次のように動く。

| | 現行 | 860万人ベース | 差 |
|---|---|---|---|
| 1号 | 1,216万 | 857万 | **−359万** |
| 2号 | 4,094万 | 4,721万 | +627万 |
| 3号 | 606万 | 339万 | **−267万** |

**1号と3号のどちらから何人移るかは、厚労省の入力データに最初から書いてある。**

## 2. ②厚年給付費推計：「新しく入る人の給料」

[`厚生年金/給付費推計/cntl.cpp`](../papers/001365945/プログラム/厚生年金/給付費推計/cntl.cpp)
（60〜81行目）で `flg_part` を受け取り、実施年度を2027年度（`partyr4 = 27`）にする。

[`厚生年金/給付費推計/seid.cpp`](../papers/001365945/プログラム/厚生年金/給付費推計/seid.cpp)
（771〜808行目）で、新しく入る人の標準報酬月額 `partbbn.AT(1, 0, 年齢, 性)` を決める。
年齢の区分は59歳以下と60歳以上で、どちらも同じ値である。

| `KAKUDAI` | 男 | 女 |
|---|---|---|
| （既存の短時間労働者） | 16.9万円 | 15.1万円 |
| 1 | 16.9万円 | 15.1万円 |
| 2 | 13.9万円 | 11.1万円 |
| 3 | 14.1万円 | 11.4万円 |
| **4** | **9.7万円** | **8.8万円** |
| 5 | 8.8万円 | 8.8万円 |

これを短時間労働者の平均の標準報酬 `bnpt` に人数で重み付けして混ぜる（821〜858行目）。
860万人ベースは、給料の低い人が大勢入る案である。

[`厚生年金/給付費推計/fileio.cpp`](../papers/001365945/プログラム/厚生年金/給付費推計/fileio.cpp)
（128〜148行目）は、外枠の短時間労働者のファイルを読む。

- `-22`：2024年10月の分（全部の番号で読む）
- `-30`（週30時間以上）・`-31`（週20〜30時間）：1〜5で読む
- `-32`（週10〜20時間）：**4番のときだけ**読む

## 3. ③国民年金

`KAKUDAI` と実施年度2027を引数で受け取る（`run_pipeline.sh` の③の呼び出し）。
1号が減った後の国民年金の給付と保険料を計算する。

---

## 4. ④基礎年金：スイッチは無い

④には `KAKUDAI` が無い。効き方は**外枠の人数だけ**である。

1. `waku.c` が外枠ファイルから号別の頭数 `SanteiTaishou` を作る
2. 1号が減って2号が増えるので、**基礎年金拠出金のうち国民年金が持つ割合が下がる**
3. 国民年金の財布が楽になり、マクロ経済スライドのカットが浅くて済む
4. **基礎年金の水準が全員分上がる**

詳しくは [基礎年金拠出金.md](基礎年金拠出金.md) の「国年の拠出金 ＝ 国年の頭数 × 単価 × 12」。

## まとめの図

```
KAKUDAI=4
  │
  ├─ ① partnin2020-2027-4.csv（厚労省の入力：年齢×性×時間×元の区分）
  │     └ simlpart.c：1号・3号から引いて2号へ移す → 外枠ファイル
  ├─ ② 新しく入る人の標準報酬（男 9.7万円／女 8.8万円）
  ├─ ③ 国民年金（1号が減った後の計算）
  ├─ ④ スイッチ無し。外枠の頭数を通じて、拠出金の割合が動く ← 基礎年金が上がる源
  └─ ⑤ 短時間労働者の保険料を収入に足す
```

## 結果（過去30年投影、所得代替率の調整終了後）

| | 現行制度 | 適用拡大 860万人 |
|---|---|---|
| 所得代替率 | 50.4% | **56.3%** |
| 基礎年金 | 25.5% | **33.2%** |
| 報酬比例 | 24.9% | 23.1% |

基礎年金が上がるぶん、厚生年金の財布の負担も増えるので、報酬比例は少し下がる。
この計算は、厚生労働省のオプション試算の公表値と照合して全項目一致している
（`検証/オプション試算/compare_option.py`、許容 相対1e-12 または 絶対1e-9）。

| 公表の財政見通し（詳細結果等2） | 外枠 | 照合項目 | 不一致 |
|---|---|---|---|
| No.15 適用拡大（約860万人）過去30年投影ケース | 3403 | 3,977 | 0 |
| No.13 適用拡大（約860万人）高成長実現ケース | 3401 | 3,977 | 0 |
