# 基礎年金拠出金について厚労省のC/C++コードで解説する

2024年財政検証で厚生労働省が公表した計算プログラム（④基礎年金）を読みながら、
**基礎年金拠出金**（コード上の名前は `Kyoshutukin`）がどう計算されているかを追う。

- コードは原本 `papers/001365945/プログラム/基礎年金/` のもの。行番号は EUC-JP を
  UTF-8 に変換したコピーで確かめた（原本とは行がずれない）
- 数字は、このリポジトリで④を動かした出力から取った（過去30年投影ケース・現行制度・2027年度）。
  現行制度の値は、公表の財政見通しと照合済み
- 数式としての整理は [年金財政検証_数式モデル.md](../年金財政検証_数式モデル.md) の
  §6「基礎年金拠出金の按分（頭割り）」と §8「有限均衡」にある

---

## 0. 全体像

基礎年金は、どこか一つの財布から払われているのではない。

1. 国民年金・厚生年金・共済の**各制度が「基礎年金拠出金」を出し合う**
2. それを基礎年金勘定がまとめて、全員の基礎年金を払う
3. 出し合う割合は「**20〜59歳の頭数**」で決まる（頭割り）

④基礎年金の [`main.c`](../papers/001365945/プログラム/基礎年金/main.c)（52〜122行目）は、
次の順に計算する。

```
ReadKokunen_jisseki()  … ③から国年の人数と給付を読む
ReadHiyousha()         … ②から被用者年金の給付を読む
waku()                 … ①の外枠から号別の頭数を作る      ← ステップ1
Atamawari()            … 給付費 → 単価 → 制度別の拠出金    ← ステップ2・3
read_file()            … 国年の保険料収入など
tyousei()              … 国年の財布を回して、スライドの終わりを探す ← ステップ4
```

## ステップ1：頭数を数える（`SanteiTaishou[制度][年度][号]`）

**2号・3号**は [`waku.c`](../papers/001365945/プログラム/基礎年金/waku.c)（31〜95行目）で数える。

- ①の外枠ファイルから、**20〜59歳**の人数を足し上げる
  （`nenrei = MIN_HIHO_NENREI(20) - 11 … 59 - 11`）
- 3号は、配偶者が加入している制度（厚年・国共・地共・私学）の頭数に入る

**1号**は③の結果を読むだけである
（[`ReadKokunen_jisseki.c`](../papers/001365945/プログラム/基礎年金/ReadKokunen_jisseki.c) 180〜181行目）。

```c
SanteiTaishou[KOKUNEN][sotai_nendo][1] += buffer[1];   // 納付者
SanteiTaishou[KOKUNEN][sotai_nendo][1] += buffer[2];   // 免除者（重み付き）
```

**1号だけは「保険料を払った分」しか数えない**。未納者は0人、免除者は一部だけ数える。
そのため、1号被保険者は1,243万人いるのに、頭数は601万人にしかならない
（2027年度）。

最後に `waku.c` の104〜118行目で、**前年度末と当年度末の平均**（年度の中央の人数）にする。

## ステップ2：拠出金で払う給付費を出す（`Atamawari.c`）

[`Atamawari.c`](../papers/001365945/プログラム/基礎年金/Atamawari.c) の前半（97〜310行目）。

- 給付を次の組み合わせに分ける
  - 制度 × 新法・旧法 × 老齢・障害・遺族
  - × **拠出金の対象（`KYOSHUTU`）か特別国庫（`TOKUBETU`）か**
  - × 基本・加給
- **マクロ経済スライドをここでかける**（190〜224行目）

  ```c
  Kyufu_Nendomatu[…] *= Cut_ritu[sotai_nendo][nenrei - UNDER_63];
  ```

- **国庫負担をここで決める**（227〜239行目）

  ```c
  if( taishou == KYOSHUTU )
      Kokko_Nendomatu[…] = Kasanmae_Kyufu_Nendomatu[…] * Kokko_Wariai[…];   // 1/2
  ```

- 支払いの遅れ（`SHIHARAIOKURE = 2` か月、110行目）を考えて、年度末の値を
  年度中の支払額に直す（295〜305行目）

## ステップ3：単価を出して割り振る（`Atamawari.c:329-345`）⭐ 本体

```c
// 1人・1か月あたりの単価 ＝ 拠出金で払う給付費の総額 ÷ 全制度の頭数 ÷ 12
Tanka[年度]       = Kyufu[SUM][…][KYOSHUTU] / SanteiTaishou[SUM][年度][SUM] / 12.;
Tanka_Kokko[年度] = Kokko[SUM][…]          / SanteiTaishou[SUM][年度][SUM] / 12;

// 制度別の拠出金 ＝ その制度の頭数 × 単価 × 12
for( seido = SUM ; seido <= SHIGAKU ; seido++ ) {
    Kyoshutukin[seido]       = SanteiTaishou[seido][年度][SUM] * Tanka[年度]       * 12;
    Kyoshutukin_Kokko[seido] = SanteiTaishou[seido][年度][SUM] * Tanka_Kokko[年度] * 12;
}
```

（原本の添字は `[sotai_nendo][nenrei - NENREI_SUM][shikyu_keitai]`。読みやすいように省略した）

### 実際の数字（過去30年投影・現行制度・2027年度）

④の出力 `kekka3003-3003-3003-3003-1120-000a.csv` の「基礎年金拠出金」
「基礎年金拠出金（国庫）」「拠出金算定対象者」ブロックから。

| | 値 |
|---|---|
| 単価 | **月42,074円／人**（うち国庫の分は21,037円＝半分） |
| 頭数の合計 | 5,324万人 |
| 拠出金の合計 | 26.9兆円 |
| 国年（1号 601万人＝11%） | 601万 × 42,074 × 12 ＝ **3.03兆円** |
| 厚年（2号 3,687万＋3号 555万） | **21.4兆円** |

3号全体（厚年555万＋共済62万＝617万人）の分は
617万 × 42,074 × 12 ≒ **3.1兆円**。[3号廃止の検証](../検証/3号廃止/README.md)で出てくる
「3号の分の拠出金3.1兆円」はこの計算である。

## ステップ4：国年の財布で使う（`tyousei.c:42-54`）

[`tyousei.c`](../papers/001365945/プログラム/基礎年金/tyousei.c) の積立金の漸化式。

```c
Tumitate[k] = Tumitate[k-1] * 利回り
  + ( 保険料 + 付加保険料
    + Kyoshutukin_Kokko[KOKUNEN]   // 収入：拠出金についてくる国庫負担（半分）
    + …
    - Kyoshutukin[KOKUNEN]         // 支出：基礎年金拠出金
    - 死亡一時金 - 寡婦年金 - 付加年金 … ) * √利回り;
```

国年の財布から見ると、実際の負担は「**拠出金 − 国庫負担 ＝ 半分**」である。
これを1号の保険料と積立金でまかなう。

④はこの式で2120年度の積立度合が1になるように `Cut_ritu`（基礎年金のカット率）を探す
（数式モデル §8.2）。そこで使う国年の拠出金は、次の形をしている。

> **国年の拠出金 ＝ 国年の頭数 × 単価 × 12**

- 国年の頭数が減る（適用拡大、1号を3号に登録し直す思考実験）
  → 国年の負担が減る → カットが浅くて済む → **基礎年金が上がる**
- 国年の頭数が増える（3号を1号へ移す形の3号廃止）→ 逆に**下がる**

基礎年金の水準をめぐる議論は、この1行で説明できる。
適用拡大がコードの上でどう定義されているかは [適用拡大.md](適用拡大.md) にまとめた。

## おまけ：特別国庫負担は頭割りの外

免除期間の分や20歳前障害など「保険料と結びつかない給付」は、`taishou = TOKUBETU` として
**頭割りに入れず、全額を国庫が持つ**（数式モデル §6.2）。国年の収支では同じ額が収入と支出の
両方に立つので、差し引きゼロの通り抜けになる。
