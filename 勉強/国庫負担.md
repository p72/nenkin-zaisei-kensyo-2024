# 国庫負担について厚労省のC/C++コードで解説する

2024年財政検証で厚生労働省が公表した計算プログラムを読みながら、
**国庫負担**（年金給付の費用のうち、保険料ではなく国の一般会計＝税金でまかなう部分）が
コードの上でどう計算されているかを追う。

- コードは原本 `papers/001365945/プログラム/` のもの。行番号は EUC-JP を UTF-8 に
  変換したコピーで確かめた（原本とは行がずれない）
- 数字は、このリポジトリで計算プログラムを動かした出力から取った（過去30年投影・現行制度）。
  公表の財政見通しと照合済み
- 先に [基礎年金拠出金.md](基礎年金拠出金.md) を読むと分かりやすい（国庫負担は拠出金と同じ仕組みで割り振られる）

---

## 0. 制度としての国庫負担

公的年金の国庫負担は、主に**基礎年金**にかかる。

- **基礎年金の給付費の1/2**を国庫が負担する（2004年改正で1/3から引き上げが決まり、2009年度から1/2）
- 保険料と結びつかない給付（保険料免除期間の分、20歳前に障害を負った人の障害基礎年金など）は、
  別建てで国庫が持つ（**特別国庫負担**）

報酬比例（厚生年金の2階部分）には、原則として国庫負担はない。

## ステップ1：割合を決める（④`dtst.c:63-77`）

[`基礎年金/dtst.c`](../papers/001365945/プログラム/基礎年金/dtst.c)。

```c
int hikiage_nendo = 2009;                                        // 25行目

for( nendo = … ; nendo <= SAISHUNENDO ; nendo++ ) {
    Kokko_Wariai[nendo] = 1. / 3. + 25. / 1000.;                 // 引き上げ前（1/3 ＋ 2.5%）
    Tokubetu_Kokko_Wariai[nendo][TOKUBETU_MENJO]      = 1.;       // 免除期間の分
    Tokubetu_Kokko_Wariai[nendo][TOKUBETU_KASAAGE]    = 1. / 4.;  // 嵩上げ（納付）
    Tokubetu_Kokko_Wariai[nendo][TOKUBETU_KASAMENJO]  = 1.;       // 嵩上げ（免除）
    Tokubetu_Kokko_Wariai[nendo][TOKUBETU_SHITASASAE] = 1.;       // 老齢福祉年金の下支え
    Tokubetu_Kokko_Wariai[nendo][TOKUBETU_GONEN]      = 1. / 8.;  // 5年年金
    Tokubetu_Kokko_Wariai[nendo][TOKUBETU_20MAE]      = 38. / 100.; // 20歳前障害

    if( nendo >= hikiage_nendo ) {
        Kokko_Wariai[nendo] = 1. / 2.;                            // 2009年度から 1/2
        Tokubetu_Kokko_Wariai[nendo][TOKUBETU_20MAE] = 2. / 10.;
    }
}
```

財政検証の見通しの期間（2024年度以降）は、`Kokko_Wariai = 1/2` で一定である。

## ステップ2：基礎年金の国庫負担（④`Atamawari.c`）

[`基礎年金/Atamawari.c`](../papers/001365945/プログラム/基礎年金/Atamawari.c)。

### 給付費の1/2（227〜239行目）

```c
if( taishou == KYOSHUTU )                                    // 拠出金で払う給付だけ
    Kokko_Nendomatu[…] = Kasanmae_Kyufu_Nendomatu[…] * Kokko_Wariai[…];   // × 1/2
```

マクロ経済スライドのカット（`Cut_ritu`）を掛けた**あとの**給付費に1/2を掛けている。
そのため、**基礎年金の水準が上がれば国庫負担も上がり、下がれば国庫負担も下がる**。

### 頭割りで各制度に配る（329〜345行目）

```c
Tanka_Kokko[年度] = Kokko[SUM][…] / SanteiTaishou[SUM][年度][SUM] / 12;        // 1人1か月あたり
Kyoshutukin_Kokko[seido] = SanteiTaishou[seido][年度][SUM] * Tanka_Kokko[年度] * 12;
```

基礎年金拠出金とまったく同じ頭割りで、国庫負担も制度ごとに配られる。
**各制度が出す拠出金の半分に、国庫負担が付いてくる**形になる。

## ステップ3：特別国庫負担（④`Atamawari.c:800-840` ほか）

保険料と結びつかない給付は、頭割りに入れず（`taishou = TOKUBETU`）、ステップ1の割合で国庫が持つ。

```c
// 保険料免除期間に対応する老齢基礎年金 → 全額
tokubetukokko[…][TOKUBETU_MENJO] += rorei_new[KOKUNEN][…][免除区分];
// 20歳前障害の障害基礎年金 → 20%
tokubetukokko[…][TOKUBETU_20MAE] += shogai_new[KOKUNEN][…][HATACHIMAE] * 2/10;
```

どれも国民年金の給付なので、特別国庫負担は**すべて国民年金の財布**に入る。

## ステップ4：財布の中でどう見えるか

### 国民年金の財布（④`tyousei.c:42-54`）

```c
Tumitate[k] = Tumitate[k-1] * 利回り
  + ( 保険料 + …
    + Kyoshutukin_Kokko[KOKUNEN]      // 収入：拠出金に付いてくる国庫負担
    + …
    - Kyoshutukin[KOKUNEN]            // 支出：基礎年金拠出金
    … ) * √利回り;
```

国民年金から見ると、実際の負担は「拠出金 − 国庫負担 ＝ 半分」になる。
特別国庫負担は、収入（国庫・特別国庫）と支出（基礎年金拠出金・特別国庫）の両方に同じ額が立つ
**通り抜け**で、国民年金の積立金には影響しない。

### 実際の数字（過去30年投影・現行制度・2027年度）

④の出力 `kekka3003-…-000a.csv` から。

| | 額 |
|---|---|
| 基礎年金の国庫負担（全制度計） | **13.44兆円**（拠出金の合計 26.88兆円の半分） |
| うち国民年金 | 1.52兆円 |
| うち厚生年金・共済 | 11.92兆円 |
| 特別国庫負担（すべて国民年金） | 0.51兆円（免除 0.28・20歳前障害 0.23） |

財政見通しの「国庫負担」の欄は、国民年金が 2.0兆円（基礎年金の分＋特別国庫＋付加年金などの分）、
厚生年金（4制度計）が 12.1兆円である。

## ステップ5：基礎年金を上げると、国庫負担は必ず半分ついてくる

ステップ2のとおり、国庫負担は「カット後の基礎年金の給付費 × 1/2」なので、
**基礎年金の水準を上げる設計は、どれも基礎年金の費用の増えた分の半分が国庫負担になる**。

実際に、基礎年金を上げる設計どうしで比べると、比はどれも **0.500** になる。
（2027〜2119年度の累積。④の運用利回りで2024年度末に割り引いた現在価値、兆円。
国庫負担は基礎年金の分で、特別国庫負担を含まない）

| ケース | 設計 | 基礎（調整後） | 基礎年金の費用の増 | 国庫負担の増（現行比） | 比 |
|---|---|---|---|---|---|
| 過去30年投影 | 適用拡大（約860万人） | 33.2% | 137.6 | 68.8（+16%） | 0.500 |
| 過去30年投影 | 現行＋調整期間の一致 | 33.2% | 127.3 | 63.6（+15%） | 0.500 |
| 過去30年投影 | 3号 按分据置型 ※ | 36.2% | 205.4 | 102.7（+24%） | 0.500 |
| 高成長実現 | 適用拡大（約860万人） | 36.2% | 114.9 | 57.5（+12%） | 0.500 |
| 高成長実現 | 現行＋一致／3号 按分据置型 ※ | 36.2% | 107.2 | 53.6（+11%） | 0.500 |

※ 非公式の独自計算。現行制度の国庫負担（同じ期間の現在価値）は、過去30年投影 433.4兆円、高成長実現 471.7兆円

- 国庫負担の増え方の違いは、**基礎年金をどれだけ上げるか**の違いだけで決まる。
  設計の良し悪しではなく、基礎年金の水準の値段である
- 高成長実現で、同じ天井（36.2%）でも適用拡大の費用の増が一致より大きいのは、
  新しく厚生年金に入った人の将来の基礎年金（未納だった期間が納付済みになる分など）も
  増えるためと考えられる（推定）

逆に、基礎年金が下がる設計では国庫負担も減る。3号を第1号に移す設計
（[3号廃止の検証](../検証/3号廃止/README.md)）で国庫負担が減るのは、国庫が得をしたのではなく、
**給付が削られた分の半分**である。

---

## 読むときの注意

- **国庫負担の増減は、基礎年金の水準の裏返しである。** 「国庫負担が増える」だけを取り出すと、
  何のための費用かが見えなくなる。基礎年金がどれだけ上がるかと一緒に読む
- **名目の年額は大きく見える。** 100年先の名目額は賃金の伸びで膨らむので、比べるときは
  割合（現行比）か現在価値で見る
- **現在価値の割り引き方で数字は変わる。** ここでは④の経済前提の運用利回りで割り引いた。
  別の割引率を使えば額は変わるが、比（0.500）は変わらない
- **特別国庫負担は別枠。** 上の比較には入れていない。免除者や20歳前障害の人が増減すれば動く
