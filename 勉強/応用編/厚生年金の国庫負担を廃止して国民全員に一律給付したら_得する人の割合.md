# 厚生年金の国庫負担を廃止して国民全員に一律給付したら、何割の人が得をするか（財政均衡） — 年金額の分布推計で重み付け

[標準報酬月額別の損得](厚生年金の国庫負担を廃止して国民全員に一律給付したら_標準報酬別の損得.md) の続き。
前の記事は「40年ずっと同じ標準報酬の会社員」という**仮想の人**で損得を出した。ここでは、厚生労働省が実際の加入記録から
推計した**65歳時点の年金額の分布**を使って、**生まれた年度ごとに何割の人が得をするか**を出した。
一律給付に別の財源で年4兆円を足した場合は [一律給付に年4兆円を上乗せしたら](厚生年金の国庫負担を廃止して国民全員に一律給付したら_上乗せ4兆円.md)。
いま年金をもらっている人の実際の分布（共済を含む）に当てはめた場合は [いまの受給者で損する人・得する人](厚生年金の国庫負担を廃止して国民全員に一律給付したら_いまの受給者.md)。

> **非公式の推定です。** 厚生労働省の試算ではありません。若い世代の得は、一律給付を全部、
> 年金と同じ利回りで運用し続ける前提に大きく頼っています（7.）。

## まとめ

| | 過去30年投影 | 成長型経済移行・継続 |
|---|---|---|
| 報酬比例の一律カット | 34.2% | 27.2% |
| 今の高齢者（1959年度生まれ）で得をする人 | **38%**（男18%・女56%） | **45%**（男20%・女68%） |
| 得をする人が過半数になる世代 | 1989年度生まれ | 1974年度生まれ |
| 世代全体で得に変わる世代 | 1989年度生まれ | 1974年度生まれ |
| いちばん若い2004年度生まれで得をする人 | 76%（男65%・女87%） | ほぼ全員 |

- **世代の中では**、男性から女性へ、報酬比例の大きい人から小さい人へお金が動く
- **世代と世代の間では**、上の世代から下の世代へお金が動く
- **この2つが、同じ1つの仕組みで同時に起きる**

## 1. この図の読み方

### 上の段：得をする人の割合

生まれた年度ごとに、**一生分で見て得をする人が何%いるか**。青が男性、オレンジが女性、黒が男女計。

### 下の段：1人あたりの損得

その世代を **100人の村** と考えると分かりやすい。過去30年投影の1959年度生まれ（得をする人38人・損をする人62人）の例：

| 図の記号 | 意味 | 値 | 100人の村で言うと |
|---|---|---|---|
| 緑の棒 | 得をする人の得の合計 ÷ 世代の全員 | **+43万円** | 得をする38人の得の合計が4,300万円（1人あたり約115万円の得） |
| 赤の棒 | 損をする人の損の合計 ÷ 世代の全員 | **−236万円** | 損をする62人の損の合計が2億3,600万円（1人あたり約377万円の損） |
| ◆黒い線 | 緑＋赤＝**男女計の平均** | **−193万円** | 村全体で1億9,300万円の損 |
| 青の点線 | 男性の平均 | −343万円 | |
| オレンジの点線 | 女性の平均 | −49万円 | |

金額はどれも **「65歳のときに一括で受け取る（払う）としたら、いくらに当たるか」** で、今の物価（2024年度）で表している。

**見方のコツ**

| 図の形 | 意味 |
|---|---|
| 緑と赤の棒が両方大きい | 同じ世代の中で、得する人と損する人に分かれている＝**世代の中の再分配** |
| 黒い線がマイナス | その世代は全体として損をして、若い世代へお金を渡している＝**世代と世代の間の移転** |
| 黒い線がプラス | その世代は全体として得をしている（上の世代から受け取っている） |
| 青とオレンジの点線が離れている | 男性と女性で損得が大きく違う |

## 2. 案の中身

[元の記事](厚生年金の国庫負担を廃止して国民全員に一律給付したら.md) と同じ。

| | 内容 |
|---|---|
| やめるもの | 2027年度から、被用者年金4制度（厚生年金・共済）への国庫負担（年12兆円ほど） |
| 年金の側 | 報酬比例を、すでに受け取っている人も含めて**全員一律に毎年同じ率で**削り、2120年度に財政を均衡させる |
| 配るもの | 国が払わずに済んだ額を、**0歳からの全員**に同じ額で毎年配る（2027年度に1人 月約7,800円、今の物価） |
| 変えないもの | 保険料、税、基礎年金 |

## 3. 計算のしかた

### 使ったデータ

厚生労働省「年金額の分布推計」（2024年財政検証の関連資料）の **65歳時点の老齢年金月額の分布**。

| | 中身 |
|---|---|
| 対象 | 1959〜2004年度生まれ（5年おき）× 男女 |
| 区分 | 月額 5万円未満／5〜7万／7〜10万／10〜15万／15〜20万／20〜25万／25万円以上 |
| 金額 | 物価で2024年度に割り戻した実質額 |
| 経済前提 | 成長型経済移行・継続と過去30年投影の2つ（分布推計が出ているのはこの2つだけ） |
| 元になった記録 | 2021年度末時点の個人の被保険者記録（5分の1抽出）。公開されていないので、このリポジトリでは分布推計そのものは再現できない（[出力カタログ](../../検証/出力カタログ.md)）。公表された結果の表を使う |

### 1人分の損得の出し方（例：1959年度生まれの男性・過去30年投影）

**① 年金月額を、基礎年金と報酬比例に分ける。** 基礎年金の満額（この世代は月6.8万円）までを基礎年金、残りを報酬比例とみなす。

**② 毎月の増減を出す。** 2027年度（この世代は68歳）から、報酬比例が34.2%減り、一律給付が入る。

**③ 一生分を足して、65歳時点の価値にする。** 毎年の増減に「その年まで生きている確率」と「割引（年金と同じ実質の運用利回り2.2%）」を掛けて足す。

| この世代の男性 | 値 |
|---|---|
| 一律給付の一生分 | **+135万円** |
| 「2027年度から毎月1万円」の一生分 | 165万円 |
| 80歳まで生きている確率 ／ 80歳の1万円の65歳時点の価値 | 74% ／ 0.72万円 |

| 65歳時点の年金月額 | 報酬比例 | カット（月） | 一生分の損得 |
|---|---|---|---|
| 8.5万円 | 1.7万円 | −0.58万円 | **+39万円**（得） |
| 12.5万円 | 5.7万円 | −1.95万円 | −186万円 |
| 17.5万円 | 10.7万円 | −3.66万円 | **−468万円** |
| 22.5万円 | 15.7万円 | −5.36万円 | −750万円 |

（例：17.5万円の人は、カットの一生分 3.66 × 165 ＝ −603万円に、一律給付の +135万円を足して −468万円）

**④ 分布で重み付けして平均する。** この世代の男性は、15〜20万円の人が41%といちばん多いので、平均は **−343万円**、得をするのは18%になる。

**⑤ 男女計にする。** 公表の男女計の分布に合うように男女を重み付ける（ほぼ半々）。
−343（男性）× 0.49 ＋ −49（女性）× 0.51 ≒ **−193万円**

若い世代は、0〜64歳に受け取った一律給付も同じ利回りで65歳まで運用して足す。そのぶん一律給付の価値が大きくなる。

## 4. 損得の分かれ目

一律給付とカットがつり合う、65歳時点の年金月額。**これより年金が少ない人は得、多い人は損**。

| 生まれた年度（65歳になる年度） | 過去30年投影（男／女） | 成長型経済移行（男／女） |
|---|---|---|
| 1959（2024） | 9.2万円／9.2万円 | 10.0万円／10.1万円 |
| 1969（2034） | 9.8万円／9.6万円 | 11.8万円／11.7万円 |
| 1979（2044） | 11.1万円／10.7万円 | 16.2万円／15.7万円 |
| 1989（2054） | 13.0万円／12.3万円 | 22.8万円／21.8万円 |
| 1999（2064） | 16.0万円／14.9万円 | 31.9万円／30.1万円 |
| 2004（2069） | 17.9万円／16.6万円 | 37.7万円／35.3万円 |

若い世代ほど、0〜64歳に受け取る一律給付が多いので、分かれ目が上がる。

### 世代ごとのお金の動き（成長型経済移行。年齢は2026年度のおよそ）

| 世代 | 世代の中 | 世代と世代の間 |
|---|---|---|
| 1969年度生まれより上（50代後半〜） | 損得が分かれる（男性→女性、報酬比例の多い人→少ない人） | **全体で損**。若い世代へ渡す側 |
| 1974年度生まれ前後（50代前半） | 損得が分かれる | **ほぼ±0**。世代の中の再分配だけに近い |
| 1979〜1994年度生まれ（30〜40代） | 損をする人もまだ残る | **全体で得**。上の世代から受け取る側 |
| 1999年度生まれより下（20代後半まで） | ほぼ全員が得。違いは得の大きさだけ | 全体で大きく得 |

過去30年投影では、世代全体で得に変わるのが1989年度生まれ（30代後半）と遅く、2004年度生まれでも損をする人が残る。

**男女で見ると**、世代の中の再分配の大部分は男性から女性への動きである。女性の平均がプラスになるのは、過去30年投影で1979年度生まれから、
成長型で1959年度生まれから（どの世代もプラス）。男性の平均がプラスになるのは、それぞれ1999年度・1984年度生まれから。

## 7. この案の再分配の性格

| | 中身 |
|---|---|
| 世代の中 | 報酬比例（＝現役のときの報酬と期間）に比例して削り、全員に同じ額を配るので、報酬比例の大きい人から小さい人へお金が動く。今の基礎年金も、報酬に比例する厚生年金保険料で定額の給付を支える再分配をしているが、それを強める |
| 世代と世代の間 | お金を受け取る時期が「老後」から「子ども・現役のとき」へ前倒しされる。早く受け取る若い世代が得をし、早く受け取れないまま報酬比例を削られる今の高齢者・中高年が損をする。賦課方式の年金でふつう見られる「上の世代ほど有利」と逆の向き |
| 財源 | 新しい税は要らない。今も厚生年金に入っている国庫負担の使い道を付け替えるだけで、国の財政は変わらない |

## 8. 読むときの注意

| 注意 | 結果への効き方 |
|---|---|
| **基礎年金を満額とみなした。** 未納・免除で基礎年金が少なく、報酬比例もある人は、報酬比例を小さく見積もっている | 得をする人の割合が少し多めに出る |
| **個人単位で計算した。** 夫が亡くなったあとに妻が受け取る遺族厚生年金のカットは入れていない | 女性の得が少し多めに出る |
| **一律給付を全部、年金と同じ実質の利回り（2.2%・3.2%）で運用し続ける前提。** 生活費や子育てに使えば、運用で増える分はずっと小さい | 若い世代の得が大きく出る。賃金上昇率で換算すると得は小さい（[世代ごとの損得](厚生年金の国庫負担を廃止して一律給付にしたら_世代ごとの損得.md)） |
| **一律カットは今のルールではできない。** 名目下限があるので、すでに受け取っている年金を名目で3割下げることはできない | 国庫負担の穴の大きさを測る物差しとして置いた |
| 区分が7つしかなく、25万円以上の区分の中身が分からない | 成長型の若い世代の割合は、この置き方に左右される |
| 分布推計は現行制度（適用拡大などを入れない場合）の分布。対象は1959年度生まれから | それより上の今の受給者は入っていない |
| 世代の平均は男女をほぼ半々で重み付けた値で、世代の人数（コホートの大きさ）は掛けていない | 世代どうしの合計の比較にはならない |
