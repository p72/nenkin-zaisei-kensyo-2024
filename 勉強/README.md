# 勉強 — 厚労省のC/C++コードから年金制度を学ぶ

2024年財政検証で厚生労働省が公表した計算プログラム（C/C++ 38,208行）を読みながら、
**年金制度の仕組みを、コードの1行1行で確かめて学ぶ**ための解説集。

制度の解説書には「頭数に応じて負担する」「マクロ経済スライドで調整する」と書いてある。
このフォルダでは、それが**どのファイルの何行目で、どんな式で**計算されているかまで降りていく。
数字はすべて、このリポジトリでプログラムを実際に動かした出力から取っている。

## 最初に知っておくこと

### 年金の3つの入り口

| 区分 | 誰が入る | 保険料 | 受け取る年金 |
|---|---|---|---|
| 第1号 | 自営業・学生・会社の保険に入れないパートなど | 定額を自分で払う | 基礎年金 |
| 第2号 | 会社員・公務員 | 給料の18.3%を会社と折半 | 基礎年金＋報酬比例 |
| 第3号 | 第2号に扶養される配偶者 | 払わない | 基礎年金 |

### 計算プログラムの6系統

原本は `papers/001365945/プログラム/` にあり、①〜⑥の順に出力を受け渡す。

```
① 被保険者推計      人口 → 労働力 → 1号・2号・3号の人数（外枠ファイル）
② 厚生年金 給付費推計 厚生年金・共済の受給者数と給付費
③ 国民年金          1号・3号の加入と、国民年金の給付
④ 基礎年金          拠出金の頭割り、マクロ経済スライドの終わり（基礎年金の水準）
⑤ 厚生年金 収支計算   積立金、報酬比例の水準、所得代替率
⑥ 分布推計          個人単位のシミュレーション（年金額の分布）
```

### 財布は2つある

- **国民年金勘定**：1号の保険料と積立金。**基礎年金の水準はこの財布だけで決まる**（④）
- **厚生年金勘定**：2号の保険料と積立金。報酬比例の水準はこの財布で決まる（⑤）

どちらも基礎年金拠出金を出し合う。財布ごとの負担の割合が「頭数」で決まることが、
このフォルダの文書に共通する鍵になる。

## 読み方の約束

- **コードの場所**：原本のファイル名と行番号で示す。原本は EUC-JP なので、UTF-8 に変換した
  コピーで行番号を確かめている（変換しても行はずれない）
- **原本の取得**：`papers/` はリポジトリに含まない。リポジトリ直下の `./fetch.sh` で
  厚生労働省の公表資料を取得する。取得前は文書内の `papers/` へのリンクが開けない
- **数字の出どころ**：このリポジトリで計算プログラムを動かした出力。現行制度と厚労省の
  オプション試算の値は、公表の財政見通しと全項目照合済み。原本にないレバーを使った数字は
  **非公式の独自計算**と明記する
- **数式としての整理**：[年金財政検証_数式モデル.md](../年金財政検証_数式モデル.md) に、
  同じ内容が式の形でまとまっている。このフォルダは、その中から話題を1つずつ取り出して
  コードに沿って読み下したもの
