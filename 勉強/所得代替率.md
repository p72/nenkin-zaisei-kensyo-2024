# 所得代替率について厚労省のC/C++コードで解説する

2024年財政検証で厚生労働省が公表した計算プログラムを読みながら、
**所得代替率**（年金を受け取り始めるときの年金額が、そのときの現役世代の手取り収入の何%か）が
コードの上でどう計算されているかを追う。財政検証の結論として報じられる「61.2%」「50.4%」は、
この数字である。

- コードは原本 `papers/001365945/プログラム/` のもの。行番号は EUC-JP を UTF-8 に
  変換したコピーで確かめた（原本とは行がずれない）
- 数字は、このリポジトリで計算プログラムを動かした出力から取った（現行制度）。
  公表の財政見通しと照合済み
- 先に [マクロ経済スライド.md](マクロ経済スライド.md)（カット率）と [有限均衡.md](有限均衡.md)
  （終了年度の決め方）を読むと分かりやすい
- 数式としての整理は [年金財政検証_数式モデル.md](../年金財政検証_数式モデル.md) の §9

---

## 0. 式はこれだけ

```
               モデル世帯の年金額（比例 × 比例のカット ＋ 基礎 × 基礎のカット）
所得代替率 ＝ ─────────────────────────────────────────────────────────── × 100
                             現役男子の平均手取り
```

**モデル世帯**は、夫が平均的な賃金で40年間厚生年金に加入し、妻がその期間ずっと第3号
（専業主婦）だった夫婦である。基礎年金は**夫婦2人分**、報酬比例は夫の分だけが入る。

コードで大事なのは、次の3つである。

1. モデル世帯の年金額と手取りを、2024年度の値から作る（⑤`shus_smodel()`）
2. その後の年度は、賃金の伸びで伸ばす（同じ関数）
3. マクロ経済スライドのカット率を掛けて割る（⑤`shus_calc8()`・`shus_out.c`）

---

## ステップ1：2024年度のモデル世帯（⑤`shus_calc.c:379-399`）

[`厚生年金/収支計算/shus_calc.c`](../papers/001365945/プログラム/厚生年金/収支計算/shus_calc.c) の
`shus_smodel()`。

```c
mdlk    = 24;          // 基準の年度（2024年度）
kasho   = 0.813;       // 可処分所得割合（額面 → 手取り）
mihanei = 0.985;

W[mdlk][0] = 455000.;  // 男子の平均標準報酬額（賞与込みの月額）

// 基礎年金：夫婦2人分（月68,000円 × 2）
Mkiso[mdlk]     = 136000. * mihanei / 0.994 / 0.996;

// 手取り：平均標準報酬 × 可処分所得割合
Kw[mdlk][0]     = round( W[mdlk][0] * kasho );

// 報酬比例：平均標準報酬 × 給付乗率 5.481/1000 × 0.926 × 40年
Mhirei[mdlk][0] = round( W[mdlk][0] * 5.481E-3 * 0.926 * 40. ) / 0.994 / 0.996;
```

- `/ 0.994 / 0.996` は、2023・2024年度にすでに実施したマクロ経済スライドを**いったん戻した**値に
  している。あとでカット率（2024年度で 0.994 × 0.996 ＝ 0.990024）を掛けると元に戻る
- `W[…][1]` 以降は参考の世帯（一元化前など）で、公表の所得代替率には `[0]` だけを使う
- `mihanei`（0.985）と `0.926` は原本の係数で、コードには説明のコメントがない

2024年度の値を計算すると、次のとおり。

| | 式 | 月額 |
|---|---|---|
| 手取り `Kw` | round(455,000 × 0.813) | **369,915円** |
| 基礎年金（夫婦） | 136,000 × 0.985 | **133,960円** |
| 報酬比例（夫） | round(455,000 × 0.005481 × 0.926 × 40) | **92,372円** |
| 年金額の合計 | | **226,332円** |

**226,332 ÷ 369,915 ＝ 61.2%**（うち比例 24.97%、基礎 36.21%）。これが2024年度の所得代替率である。

④基礎年金も、同じ値を別の場所で持っている
（[`基礎年金/dtst.c`](../papers/001365945/プログラム/基礎年金/dtst.c):108-109）。

```c
MODEL_PENSION = 133960 / ( 0.994 * 0.996 ) ;   // 夫婦2人の基礎年金
MODEL_WAGE    = 369915;                         // 現役男子の平均手取り
```

④が出す「代替率換算」は、この2つから計算した基礎年金の分だけの所得代替率である
（[マクロ経済スライド.md](マクロ経済スライド.md) のステップ6）。

## ステップ2：将来の年度へ伸ばす（`shus_calc.c:401-416`）

```c
for( k = mdlk+1 ; k <= Ke ; k++ ){
    // 手取り：賃金の伸び × 手取り割合の変化
    Kw[k][0]     = Kw[k-1][0] * W[k][0] / W[k-1][0]
                     * (0.91 - Prema[1][k-1]/2.) / (0.91 - Prema[1][k-2]/2.);
    // 報酬比例：手取りと同じ率で伸ばす
    Mhirei[k][0] = Mhirei[k-1][0] * Kw[k][0] / Kw[k-1][0];
    // 基礎年金：賃金の伸び × 手取り割合の変化
    Mkiso[k]     = Mkiso[k-1] * (1.0 + H[k-1])
                     * (0.91 - Prema[1][k-1]/2.) / (0.91 - Prema[1][k-2]/2.);
}
```

- `H` は賃金上昇率、`Prema[1]` は厚生年金の保険料率（上限18.3%、`shus.c:142`）。
  `0.91 − 保険料率/2` は、本人負担の保険料が変わったときの手取りの割合の変化を表す
- 年金額（カット前）も手取りも**同じ賃金の伸びで伸ばす**。そのため、**カットがなければ
  所得代替率は変わらない**。所得代替率を動かすのはカット率だけである

## ステップ3：カット率を掛けて割る

### 年度ごと（⑤`shus_out.c:386-411`）

[`厚生年金/収支計算/shus_out.c`](../papers/001365945/プログラム/厚生年金/収支計算/shus_out.c)。
出力 `03summary…_08sum.csv` の「経済前提等」ブロックを書く部分。

```c
r1h = Mhirei[k][0] * Escutrrh[k][67];     // 報酬比例 × 比例のカット（67歳）
r1k = Mkiso[k]     * Escutrrt[k][67];     // 基礎年金 × 基礎のカット（67歳）
r1  = r1h + r1k;

所得代替率 = r1 / Kw[k][0] * 100.;   うち比例 = r1h / Kw * 100.;   うち基礎 = r1k / Kw * 100.;
```

カットは**67歳**の値を使う。65歳で受け取り始めた人の年金額は、67歳までは賃金に連動して
改定される（新規裁定）ので、そこまでの調整を含めた値になる。

### 最終の値（⑤`shus_calc.c:345-355`）

```c
dtemp = ( Mhirei[Ke][0] * Escutrrh[Ke][67] + Mkiso[Ke] * Escutrrt[Ke][67] ) / Kw[Ke][0] * 100.;
printf("  一元化モデル：%.13f \n", dtemp);
```

`Ke` は計算の最終年度。調整が終わったあとはカット率が変わらないので、これが
「給付水準の調整終了後の所得代替率」になる。⑤を動かすと画面に出る「最終代替率」がこれである。

## 結果：過去30年投影ケース（現行制度）

出力 `03summary.3003-…-000_08sum.csv` から。

| 年度 | 所得代替率 | うち比例 | うち基礎 | モデル年金額（月額） | 手取り（月額） |
|---|---|---|---|---|---|
| 2024 | **61.2%** | 25.0% | 36.2% | 226,332円 | 369,915円 |
| 2030 | 59.9% | 24.9% | 35.0% | 240,403円 | 401,665円 |
| 2040 | 56.3% | 24.9% | 31.4% | 253,649円 | 450,438円 |
| 2050 | 52.5% | 24.9% | 27.6% | 269,149円 | 512,745円 |
| **2057** | **50.4%** | 24.9% | 25.5% | 282,908円 | 561,419円 |
| 2060以降 | 50.4% | 24.9% | 25.5% | （賃金とともに伸びる） | |

- 報酬比例の調整は2026年度に終わり、24.9%で止まる
- 基礎年金の調整は2057年度まで続き、36.2% → 25.5% に下がる。**所得代替率の低下の大部分は基礎年金**である
- 調整が終わる2057年度以降は、年金額も手取りも同じ率で伸びるので、所得代替率は50.4%のまま変わらない

### 「所得代替率が下がる」＝「年金額が減る」ではない

同じ表の年金額は、名目では 226,332円 → 282,908円（2057年度）と**増えている**。
物価で割り戻した実質でも、2057年度は 210,741円（2024年度比 −7%）で、2100年度には
261,150円まで増える（同じファイルの「物価割り戻し」の列）。

所得代替率は「**現役の手取りに比べて**どれだけか」なので、年金が増えても、手取りのほうが
速く増えれば下がる。

### 50%という線

2004年改正法の附則は、次の財政検証までに所得代替率が**50%を下回る**と見込まれるときは、
給付水準の調整を終えるなどの措置を講ずるとともに、給付と負担のあり方を検討して所要の措置を
講ずるとしている（厚生労働省
[年金制度の仕組みと考え方 第5](https://www.mhlw.go.jp/stf/nenkin_shikumi_05.html)）。
この線が問われるのは「次の財政検証まで」（5年後）の値で、100年後の値ではない。
過去30年投影でも2029年度は約60%なので、この規定には当たらない。調整終了後の50.4%は、
線のすぐ上に着地する見通しということである。

## 所得代替率を読むときの注意

- **モデル世帯の数字である。** 単身者、共働き、自営業（1号だけの人）は、分母も分子も違う。
  基礎年金を夫婦2人分数えるので、片働き世帯の値は高く出る
- **受け取り始めるときの数字である。** 受給開始後は物価で改定される（68歳以降）ので、
  年齢が上がると所得代替率は下がっていく
- **基礎と比例の内訳を見る。** 同じ所得代替率でも、基礎年金が低いと、年金が基礎年金だけの人
  （1号の期間が長い人）が大きく影響を受ける

```
2024年度のモデル世帯（shus_smodel）
  手取り   455,000 × 0.813         ＝ 369,915円
  基礎     136,000 × 0.985          ＝ 133,960円（夫婦2人）
  比例     455,000 × 5.481‰ × 0.926 × 40 ＝ 92,372円（夫）
        │
        ├─ 将来へ：年金額も手取りも賃金の伸びで伸ばす（カットがなければ代替率は一定）
        │
        └─ カット率を掛ける（67歳の値）
             比例 × Escutrrh（⑤が決める） ＋ 基礎 × Escutrrt（④が決める）
                              ÷ 手取り × 100
                                 │
                    2024年度 61.2% → 2057年度 50.4%（過去30年投影）
```
