# 1シナリオを流すと何が手に入るか

`検証/実行/run_pipeline.sh` を1本流したときに出てくるものの棚卸し。
中身の数字ではなく**取れる量の一覧**です。実測は過去30年投影ケース
（`3003 1 1 0 2`、通常試算）。

| 系統 | ファイル | 容量 |
|---|---|---|
| ① 被保険者推計 | 104本 | 0.05 GB |
| ② 厚生年金 給付費推計 | 43本 | 1.38 GB |
| ③ 国民年金 | 10本 | 0.02 GB |
| ④ 基礎年金 | 6本 | 0.01 GB |
| ⑤ 厚生年金 収支計算 | 14本 | 0.69 GB |
| **合計** | **177本** | **2.15 GB** |

## 共通の軸

どのファイルもこの軸の組み合わせです。

| 軸 | 範囲 |
|---|---|
| 年度 | 2020〜2125年度（公表の対象は2024〜2120年度） |

```
公的計 / 被用者計 / 国年２号
旧厚(70未満) / 旧厚(70以上) / 旧厚12種(パート含まず) / 旧厚3種
旧厚短時間(今後の適用拡大対象者を含む) / 国共2号 / 地共2号 / 私学2号
1号計 / 1号(一般) / 1号(任意)
3号計 / 旧厚3号 / 国共3号 / 地共3号 / 私学3号
人口差分 / 人口央 / 人口末
適用拡大202410計（元１号／元３号／元その他）
適用拡大１段階目・２段階目 × 元の資格（１号・３号・その他）
                        × 週労働時間（30時間以上／20〜30／20未満）
```

適用拡大は**「もともと何号だったか」×「週何時間働いていたか」**まで分かれて
出ます。適用拡大オプションの効果を分解したいときはここです。

## 手に入らないもの

- **個人単位のデータ。** ⑥分布推計はマイクロシミュレーションですが、同梱
  データに個人ごとの加入月数がなく、基準年齢27歳以上のコホートは `-nan` に
  なります（仕様書 §12.5・付録B）。17歳コホートだけ数値が出ます。
- **繰上げ・繰下げ。** モデルに入っていません（§10.7）。65歳受給開始の
  年金額だけです。
- **地域別・産業別。** 軸そのものがありません。
- **標準報酬の個人分布。** ②の `bunpu_bb` は年度×性×年齢の集計分布までです。
