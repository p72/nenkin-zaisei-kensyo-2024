# 拠出金按分据置型で誰の年金が増えるか

按分据置型では基礎年金が上がり、報酬比例が下がる（2段階均衡）。基礎年金は**定額**、報酬比例は**賃金比例**なので、賃金が高い人ほど比例の減少が効く。どこかで損得が逆転しないかを見る。`bunpai.py` が出力ファイルから計算したもの。

**所得代替率の「うち基礎」は夫婦2人分である。** モデル世帯は「夫が厚生年金に40年加入、妻が40年間第3号」で、基礎年金は2本、報酬比例は夫の1本。損益分岐は世帯の形で変わる。

```
  片働き夫婦（モデル世帯）  k* = Δ基礎       ÷ |Δ比例|
  単身・共働きの1人          k* = (Δ基礎 / 2) ÷ |Δ比例|
  k = 本人の賃金 ÷ モデルの賃金
```

| ケース | Δ基礎（夫婦2人分） | Δ比例 | k*（片働き夫婦） | k*（単身・共働き） |
|---|---|---|---|---|
| 過去30年投影 | +10.70pt | -3.15pt | 3.40 倍 | **1.70 倍** |
| 高成長実現 | +4.27pt | +0.00pt | —（比例が減らない） | —（比例が減らない） |

## その倍率に届く人はいるか

| 項目 | 値 |
|---|---|
| 平均総報酬（月、賞与を均して含む。概算） | 約 405,000円 |
| 標準報酬月額の上限 | 650,000円 |
| 上限 ÷ 全体の平均（月給だけで見た k の上限の目安） | 約 1.6 倍 |
| モデルの賃金 | 男子の平均なので全体の平均より高い。上限 ÷ モデルの賃金はこれより小さい |
| 賞与 | 標準賞与額は1回150万円までを別枠で算入するので、賞与の多い人は k がさらに上がる |

**単身・共働きの1人は、賃金がモデルの約 1.7 倍を超えると損をする。** 月給だけで見た上限（全体平均比で約 1.6 倍、モデル比ではそれ以下）の**すぐ上**にあたる。月給だけでは届きにくいが、賞与の多い高所得者は越えうる（推定）。つまり過去30年投影では、**高所得の単身者・共働き世帯は損益分岐の境目にいて、一部は報酬比例の減少が基礎年金の増加を上回る**。「全員が得をする」とは言えない。

片働き夫婦（モデル世帯）は損益分岐が高く、上限に張りついても得をする。ただしこの世帯は、妻がまさに新しく国民年金の保険料（2027年度で月約17,600円）を払う世帯である。所得代替率の分母は夫の手取りなので、**その負担は所得代替率には現れない**。

高成長実現ケースは報酬比例が減らないので、世帯の形によらず給付は減らない（片働き夫婦の保険料負担は別）。

> **注意。** 所得代替率はモデル世帯の値で、加入期間・賞与の扱いはモデルのまま固定している。個々人の年金額を示すものではない。k の上限は概算。
