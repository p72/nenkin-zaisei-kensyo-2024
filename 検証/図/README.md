# 図

プレゼン用の図。データは `検証/実行/run_all_cases.sh` の実行結果（仕様書 §15.0.0）、
公表値は厚生労働省「令和6(2024)年財政検証結果の概要」3頁
（https://www.mhlw.go.jp/content/001270476.pdf ）。

```bash
python3 検証/図/make_chart.py [出力パス]
```

必要なもの: matplotlib、日本語フォント（`Noto Sans CJK JP`）。

## 所得代替率_8ケース.png

経済前提8ケースの所得代替率を、厚生年金（報酬比例部分）と基礎年金部分に
分けた横積み上げ棒。◆が厚労省の公表値で、公表値のある3ケースで一致する。

読み取れること:

- 将来の所得代替率は経済前提で **39.8%〜58.1%** と大きく変わる
  （足元2024年度は61.2%）
- 比例部分は**約25%でほぼ一定**。差はほとんど基礎年金部分で生じる
- 最も悪い2ケース（1人当たりゼロ成長）は比例部分も削られ、
  給付水準の調整が均衡期間内（2120年度まで）に終わらない

1人当たりゼロ成長ケースは公表資料が単一の所得代替率を示していないため
（国民年金の積立金が枯渇し賦課方式へ移行）、照合対象外。
経済変動ケース4本も概要には載っていない。

配色は `dataviz` スキルの検証済みパレット（light モードで全チェック PASS）。

## シナリオ_調整期間の一致.png / ..._表.png

シナリオ1本を掘るタイプの1枚。**過去30年投影ケース**に
「マクロ経済スライドの調整期間の一致」を入れると何が起きるかを、
通常試算と並べます。

```bash
検証/実行/run_pipeline.sh 3003 1 1 0 2                       # 通常試算
SKIP_BUILD=1 TOUGOU=1 YOBI=010 YOBI2=011 STEPS=45 \
    検証/実行/run_pipeline.sh 3003 1 1 0 2                   # 調整期間の一致

python3 検証/図/make_scenario_chart.py --log <実行ログ>
```

`--log` に `run_pipeline.sh` の出力を渡すと、表に工程別の計算時間が入ります。
数値はすべて実行結果から読みます（スクリプトに焼き込んでいません）。
公表値だけは `PUB` に持っています（詳細結果等1 No.03・詳細結果等2 No.23）。

読み取れること:

- 所得代替率は **50.39% → 56.16%（+5.77pt）**。基礎年金が +7.73pt 上がり、
  報酬比例が −1.95pt 下がる
- 給付水準調整の終了年度は、基礎年金が **2057→2036年度（21年短縮）**、
  報酬比例が **2026→2036年度（10年延長）**。これが「一致」の意味
- 2070年度のモデル年金額（実質<対物価>）は **22.49 → 25.06万円/月**
- 通常試算の線は2057年度まで下がり続けて 50% をわずかに上回るところで止まる。
  一致させると2036年度で止まるので、以降の世代の水準が保たれる

照合は `検証/オプション試算/compare_option.py` で 3,977＋2,134 = **6,111項目、
不一致ゼロ**。所得代替率は15桁一致します。

計算時間（4 vCPU の Linux コンテナ、ビルド込み）:

| | 通常試算 | 調整期間の一致 |
|---|---|---|
| ビルド・下準備 | 62秒 | 1秒 |
| ① 被保険者推計 | 1秒 | ― |
| ② 厚生年金 給付費推計 | 83秒 | ― |
| ③ 国民年金 | 1秒 | ― |
| ④ 基礎年金 | 1秒 | 1秒（2周で） |
| ⑤ 厚生年金 収支計算 | 7秒 | 8秒 |
| **合計** | **155秒** | **10秒** |

オプション側が10秒で済むのは、①②③を通常試算のまま使い回して④⑤だけ
流し直せるから（`STEPS=45`）。②の83秒が全体の半分を占めます。
